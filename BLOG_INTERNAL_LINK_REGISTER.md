## Ongoing Process

When a new blog article is prepared:

1. Review which existing articles the new article should link to.
2. Review which older articles could naturally link to the new article.
3. Propose the internal-link map before editing any article.
4. Implement links only after approval.
5. Add approved implemented links to this register after validation.
6. Do not add links solely to meet a numerical target; each link must genuinely help the reader.
